This repository contains a personal portfolio website built with Next.js and React. Its visual direction uses a neo-brutalist palette and typography, with motion and scroll-based interactions supporting the main portfolio sections.

## Sections

- **Hero and introduction**
- **About and technical skills**
- **Selected projects**
- **Experience and certifications**
- **Leadership and campus involvement**
- **Contact information**

## Tech stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- ESLint

## Run locally

### Requirements

- Node.js compatible with the Next.js version in `package.json`
- npm

```bash
git clone https://github.com/kishorekrrish3/My-Portfolio.git
cd My-Portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Customization

Portfolio content is organized into reusable components. Update the relevant section components and project data to keep experience, skills, projects, certifications, and contact details current.
